# Task Manager

## Backend

    cd backend
    composer install
    cp .env.example .env
    php artisan key:generate
    php artisan jwt:secret

Edit `.env`:

    DB_DATABASE=task_manager
    DB_USERNAME=root
    DB_PASSWORD=

    mysql -u root -p -e "CREATE DATABASE task_manager;"
    php artisan migrate --seed
    php artisan serve

## Frontend

    cd frontend
    npm install
    cp .env.example .env
    npm run dev
